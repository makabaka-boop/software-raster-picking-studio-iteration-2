# Canvas 三角网格查看器

一个不依赖 WebGL 的小型软件光栅器：TypeScript 负责几何与光栅化，渲染在 Web Worker 中完成，主线程只把颜色缓冲写入 Canvas `ImageData`。

## 能力与约束

- 最多 `500` 个输入三角形。
- 输出分辨率最大 `640×480`。
- 相机朝相机空间 `+Z` 观察；近裁剪面固定为 `z=1`。
- 跨越近裁剪面的三角形先在相机空间裁切，再投影和扇形三角化。
- 近裁剪面内使用相机空间 `z` 的深度缓冲，近面获胜。
- 颜色使用 `1/z` 透视正确插值。
- 每帧同时生成：
  - RGBA8 颜色缓冲；
  - `Float32Array` 深度缓冲，背景为 `Infinity`；
  - `Int32Array` 原始三角形 ID 缓冲，背景为 `-1`；
  - 可切换的可见边层 `Uint8Array`（仅在请求时生成，关闭时为 `null`）。
- 可见边层只画当前视角真正可见的三角形边：
  - 边复用与填充相同的相机变换、近平面裁切和投影（每个网格顶点只变换一次）；
  - 逐像素对照该帧最终的深度缓冲判定，被前景表面遮住的背面边不会显示；
  - 共享边以原始顶点下标的无序对为键去重，输出与三角形提交顺序无关；
  - 不画近平面裁切产生的合成封口边，只画原始三角形边；
  - 边层从不写颜色、深度或 ID 缓冲，只在提交后合入显示用的 `ImageData` 副本。
- 鼠标拾取只读取当前已提交帧的 ID 缓冲，不执行独立的射线/近似命中算法。
- 旋转、缩放、换网格或切换线框都使用同一个单调帧序号；迟到 Worker 帧不会替换新画面，也不会替换深度、边层和拾取数据。

## 代码结构

- `src/renderer.ts`：相机变换、近平面 Sutherland–Hodgman 裁切、投影、边缘函数、透视插值和深度缓冲；可见边层的逐边裁切、像素中心覆盖与逐像素深度判定。
- `src/renderWorker.ts`：Worker 包装；颜色、深度、ID 和（可选的）边层 `ArrayBuffer` 以 Transferable 对象在同一条消息里回传。
- `src/viewer.ts`：Canvas `ImageData`、旋转/尺寸/线框请求合并、帧序号和迟到帧提交规则；边色只合入显示副本。
- `src/frame.ts`：帧提交（基础缓冲与边层在同一快照原子提交）、尺寸/序号检查和基于 ID 缓冲的拾取。
- `src/main.ts`：可交互演示，拖动旋转，点击查询三角形 ID，复选框切换可见边。
- `test/`：可手算的小三角形测试，覆盖近裁剪、遮挡、透视插值、边界像素、限制值、换帧竞争和线框快速切换。

## 光栅化约定

像素在整数像素中心 `(x + 0.5, y + 0.5)` 求值。相邻三角形共享边采用确定性的归属规则：竖直向上（y 减小）的边和水平向左（x 减小）的边允许 `E === 0`，其余边要求 `E ≥ 1e-7` 的微小容差。任意共享边只被两侧三角形之一拥有，边界像素的归属不随提交顺序变化，也不会被两个三角形重复写入。

边覆盖同样以像素中心判定：中心到边的垂直距离不超过 `0.5 - 1e-6`（恰为 0.5 的并列点排除），投影参数夹在端点之间。可见性在该像素中心按透视校正的边深度与该帧深度缓冲比较（含一个覆盖 Float32 舍入的 `1e-5` 相对容差）；有限深度表示有更近表面，边被遮住，背景的 `Infinity` 视为远平面。边与网格边的顶点无序对一一对应，因此共享边天然只绘制一次。
